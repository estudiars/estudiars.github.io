Para hacer las alas de hada necesitarás alambre, cinta adhesiva y medias. Lo primero que debes hacer es doblar el alambre a la mitad y crear la forma de un corazón como se muestra en la foto. Haz lo mismo con el otro alambre y sujétalos bien con la cinta adhesiva. Corta las piernas de las medias y colócalas en los alambres. Para más detalles sobre cómo hacer las alas, puedes visitar este enlace .

Para hacer alas de hada hay varias formas. Una de ellas es usando colgadores y medias. Puedes seguir los siguientes pasos:

1. Usa cortaalambres para recortar la parte del gancho de cuatro colgadores de alambre. Ten cuidado de cortar el gancho por donde empiece la parte curva pero no debes cortar por esa parte curva.
2. Dobla los colgadores hasta que tengan una forma aproximada de óvalo o de círculo.
3. Superpón dos de las partes curvas y pégalas con cinta de embalar.
4. Usa más cinta de embalar para unir ambos conjuntos de alas.
5. Hazles ajustes a las alas según sea necesario para que tengan la forma que desees.
6. Estira una media hasta la rodilla sobre cada una de las alas y usa cinta de embalar para asegurarla.
